# Agent Studio 项目手册

## 项目架构

Agent Studio 是一个本地单用户 Agent 工作台。浏览器 UI 与 FastAPI API 同源运行，默认端口为 8080。
应用通过 OpenAI 兼容的 HTTP API 连接 vLLM，推理服务默认端口为 8000。
默认聊天模型是 Qwen/Qwen3-4B-Instruct-2507，可以通过环境变量切换到 Qwen3-0.6B 或 Qwen3-1.7B。

## Memory 记忆

短期记忆保存当前会话的用户和助手消息。构造模型上下文时保留有限轮次，并对更早的消息截取摘要片段。
长期记忆由用户在记忆面板主动保存，也可在聊天中输入 /remember 后跟内容，或使用“记住：内容”。
长期记忆跨会话共享，删除会话不会删除长期记忆。用户可以单独删除记忆。
记忆、文档和历史消息保存在 SQLite 数据库中，应用重启后仍然存在。

## RAG 知识库

文档支持 UTF-8 TXT、Markdown、CSV、JSON，以及可提取文本的 PDF。
文档按长度分块，并保留重叠窗口、原始文件名和 PDF 页码。
默认使用中英文 BM25 关键词检索，无需下载向量模型。
启用向量服务后使用 Qwen3-Embedding-0.6B，通过余弦相似度与 BM25 的倒数排名融合（RRF）构成混合检索。
更换 Embedding 模型或后端后需要重建索引。文档按 SHA256 去重。
扫描版 PDF 需要先做 OCR；本项目没有集成 OCR。

## Agent 执行链路

请求进入后读取会话、召回长期记忆、检索知识库，再进入模型与工具的循环。
工具包括 search_knowledge、recall_memory、calculate 和 current_time。
工具参数经过校验，计算器仅接受受限数学表达式，不执行任意 Python 或 shell。
最大循环次数包含最终回答，防止无界工具调用。
UI 通过 SSE 展示文本增量、检索来源、工具参数、结果和 token 使用量。
不展示或保存模型隐藏思考过程。

## 本地部署

应用进程与 vLLM 分开启动。默认监听 127.0.0.1。
离线 demo 模式用于界面与数据流程验证，没有真实模型推理，输出会明确标记。
单用户版本没有多租户隔离。访问令牌通过 AW_API_TOKEN 配置。
